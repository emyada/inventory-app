# ห้องคลัง — IEM Workshop Inventory

เว็บแอปสต๊อก/ผลิตแบบ POS สำหรับโรงงานผลิต IEM แบบสั่งทำ ใช้ Supabase เป็นฐานข้อมูล+ระบบล็อกอินจริง รองรับผู้ใช้พร้อมกัน 15-20 คน ใช้ได้ทั้งบนคอมและมือถือ (ติดตั้งเป็นแอปได้แบบ PWA)

## สิ่งที่มีให้แล้ว
- ล็อกอินจริงด้วยอีเมล/รหัสผ่าน (Supabase Auth) — มีแค่คุณที่สร้างบัญชีใหม่ได้
- 3 สิทธิ์: `admin` (หัวหน้าช่าง/หัวหน้าสต๊อก — ทำได้ทุกอย่าง), `staff` (ทีมผลิต — กดผลิต+ดูคลัง), `purchasing` (จัดซื้อ — ดูคลัง+รับของเข้า)
- ข้อมูลซิงก์เรียลไทม์ทุกอุปกรณ์ (ใครแก้ ทุกคนเห็นทันที)
- ผลิต/เบิกของ ต้องกรอกออเดอร์+ชื่อช่างเสมอ, ยกเลิกออเดอร์ได้ (คืนของกลับคลัง), ประวัติเข้า-ออกครบ (admin), รายงานผลิตแยกตามหมวด/รุ่น (admin)
- ปุ่มส่งออก CSV และปุ่ม "ส่งเข้า Google Sheet" ในหน้าคลัง+รายงาน

## สิ่งที่ยังไม่รวม (ทำเพิ่มได้ทีหลัง)
- **Push notification** (แจ้งเตือนป๊อปอัพ) — ต้องเพิ่ม Web Push API + Supabase Edge Function แยกต่างหาก ไม่ได้รวมไว้ในนี้ ถ้าต้องการ บอกได้ ผมช่วยต่อให้ได้
- การอัปโหลดข้อมูลวัตถุดิบ/รุ่นจริงทั้ง 100+ รายการ — ตอนนี้ฐานข้อมูลว่างเปล่า ต้องกรอกเองผ่านแอป (หรือ import ผ่าน Supabase Table Editor เป็น CSV ได้เร็วกว่า)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1) สร้างโปรเจกต์ Supabase (ฟรี)
1. ไปที่ [supabase.com](https://supabase.com) → สมัคร/ล็อกอิน → New Project
2. ตั้งชื่อโปรเจกต์ + รหัสผ่านฐานข้อมูล (เก็บไว้ดีๆ) + เลือก region ใกล้ไทย (Singapore)
3. รอสร้างเสร็จ (~2 นาที)

### 2) รันฐานข้อมูล
1. ในโปรเจกต์ Supabase → เมนูซ้าย **SQL Editor** → New query
2. เปิดไฟล์ `supabase/schema.sql` ในโปรเจกต์นี้ คัดลอกทั้งหมดไปวาง แล้วกด Run
3. เสร็จแล้วจะมีตาราง: `profiles`, `materials`, `models`, `model_bom`, `transactions`, `stock_log`, `app_settings`

### 3) สร้างบัญชีผู้ใช้คนแรก (ตัวคุณเอง เป็น admin)
1. เมนูซ้าย **Authentication → Users → Add user** → กรอกอีเมล/รหัสผ่าน → Create user
2. ระบบจะสร้างโปรไฟล์ให้อัตโนมัติ (role เริ่มต้นเป็น `staff`)
3. ไปที่ **Table Editor → profiles** → หาแถวของคุณ → แก้ `role` เป็น `admin` → Save
4. คนอื่นๆ (ทีมผลิต 15 คน + จัดซื้อ) ทำแบบเดียวกับข้อ 1 ได้เลย (role เริ่มต้น `staff` ก็พอสำหรับทีมผลิต) — ส่วนของจัดซื้อ ปรับ role เป็น `purchasing` ในหน้า Table Editor หรือในแอป (หน้าตั้งค่า หลังล็อกอินเป็น admin แล้ว จะมีปุ่มเปลี่ยน role ให้ทุกคนโดยไม่ต้องเข้า Supabase อีก)

### 4) ตั้งค่าโปรเจกต์นี้ให้ต่อกับ Supabase ของคุณ
1. ในโปรเจกต์ Supabase → **Project Settings → API**
2. คัดลอก `Project URL` และ `anon public` key
3. ในโฟลเดอร์นี้ คัดลอกไฟล์ `.env.example` เป็น `.env` แล้วใส่ค่า:
   ```
   VITE_SUPABASE_URL=https://xxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJxxxxxxx...
   ```

### 5) รันทดสอบในเครื่อง
```bash
npm install
npm run dev
```
เปิด `http://localhost:5173` แล้วล็อกอินด้วยบัญชีที่สร้างไว้

## Deploy ขึ้นใช้งานจริง (ฟรี — ผ่าน Vercel)

1. สร้าง repo บน GitHub แล้ว push โค้ดโฟลเดอร์นี้ขึ้นไป (ไม่ต้อง push `.env` — มี `.gitignore` กันไว้ให้แล้ว)
2. ไปที่ [vercel.com](https://vercel.com) → สมัคร/ล็อกอินด้วย GitHub → **New Project** → เลือก repo นี้
3. ในหน้า "Environment Variables" ใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` (ค่าเดียวกับใน `.env`)
4. กด **Deploy** — รอ ~1 นาที จะได้ลิงก์เช่น `https://iem-inventory.vercel.app`
5. แชร์ลิงก์นี้ให้ทีมงานทุกคนได้เลย — เปิดจากคอมหรือมือถือก็ได้ ใช้ลิงก์เดียวกัน

### ติดตั้งเป็น "แอป" บนมือถือ/คอม (PWA)
ไม่ต้องขึ้น App Store — เปิดลิงก์เว็บแล้วกด:
- **iPhone (Safari):** ปุ่มแชร์ → "Add to Home Screen"
- **Android (Chrome):** เมนูจุดสามจุด → "Add to Home screen" / "Install app"
- **คอม (Chrome/Edge):** ไอคอนติดตั้ง (⊕) ที่ช่อง URL → Install

จะได้ไอคอนแอปจริงบนหน้าจอ เปิดแล้วเต็มจอไม่มีแถบเบราว์เซอร์

## Google Sheets sync

ปุ่ม "ส่งเข้า Google Sheet" ในหน้าคลัง/รายงาน ต้องตั้งค่า Webhook 1 ครั้งก่อนใช้:

1. เปิดไฟล์ `google-apps-script/Code.gs` ในโปรเจกต์นี้ — มีขั้นตอนละเอียดในไฟล์
2. สรุปคร่าวๆ: สร้าง Google Sheet ที่จะรับข้อมูล → Extensions > Apps Script → วางโค้ดจากไฟล์นั้น → Deploy เป็น Web App (Anyone can access) → คัดลอก URL ที่ได้
3. ล็อกอินแอปด้วยบัญชี admin → กดไอคอนตั้งค่า (⚙) มุมขวาบน → วาง URL → บันทึก
4. ทดสอบกดปุ่ม "ส่งเข้า Google Sheet" ในหน้าคลังหรือรายงาน — ข้อมูลจะไปโผล่เป็นแท็บใหม่ในชีตนั้น

## โครงสร้างโปรเจกต์
```
src/
  lib/supabaseClient.js      ตัวเชื่อม Supabase
  context/AuthContext.jsx    สถานะล็อกอิน + role
  hooks/useInventoryData.js  โหลด/แก้ไขข้อมูลทั้งหมด + realtime sync
  components/                ฟอร์ม/โมดัลต่างๆ ที่ใช้ร่วมกัน
  views/                     หน้าผลิต / คลัง / รายงาน / ตั้งค่า
  App.jsx                    ประกอบทุกอย่างเข้าด้วยกัน
supabase/schema.sql          สร้างตาราง + สิทธิ์การเข้าถึงข้อมูล (RLS)
google-apps-script/Code.gs   โค้ดฝั่ง Google Sheet สำหรับรับรายงาน
```

## จุดที่ควรรู้ / ปรับต่อได้
- สิทธิ์แก้ไข qty วัตถุดิบตอนนี้เปิดให้ทุก role (จำเป็นสำหรับตอนกดผลิต/รับของ) แต่การ**เพิ่ม/ลบ**รายการวัตถุดิบและรุ่นสินค้า จำกัดเฉพาะ `admin` แล้วผ่าน RLS จริงในฐานข้อมูล (ไม่ใช่แค่ซ่อนปุ่มในหน้าจอ)
- อยากเพิ่ม push notification ทีหลัง แนะนำ Supabase Edge Function + Web Push API หรือใช้บริการสำเร็จรูปอย่าง OneSignal ต่อกับ Supabase ก็ได้ — บอกได้เลยถ้าอยากให้ช่วยต่อ
